# Velvetune

A retro early-computing styled music player APK for Android with real-time audio streaming.

## Features

- Deep Navy Blue, Classic Parchment, Game Boy DMG, Macintosh 1-Bit, and Amber CRT theme palettes.
- Retro tape deck cassette player with synchronized spinning spools.
- Isolated squigglevision line-boil karaoke lyrics synchronized with playback.
- Pulsating audio waveform visualizer.
- Song search and stream extraction via InnerTube YouTube architecture.
- Tactile early-computing beveled controls with volume stepper and dithered scrubber.

## Architecture

- Audio Engine: Just Audio
- Stream Resolution: InnerTube YouTube Audio Extraction
- State Management: Provider
- Framework: Flutter Android APK

## Build

```bash
flutter pub get
flutter build apk
```
